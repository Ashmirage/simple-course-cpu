# 双人共用：12 条单周期 CPU

Vivado 2019.2，EGO1，xc7a35tcsg324-1。A：add.w/sub.w/addi.w/and/or/xor；B：lu12i.w/ld.w/st.w/beq/bne/b。统一 decoder 和 cpu_core。

直接打开 project/cpu_stage1.xpr。硬件顶层 ego1_top，支持 12 条。如提示时钟 IP 需要生成，右键 clk_wiz_0 → Generate Output Products。

仿真顶层 tb_cpu_twelve，运行 Behavioral Simulation，预期 `TWELVE INSTRUCTION TEST PASS: 2026, 7887, 8704`。顶层 tb_cpu_twelve_injected 可验证加法被故意换成减法时报告第 3 项失败。

综合、实现，确认时序通过后生成 bitstream，下载 project/cpu_stage1.runs/impl_1/ego1_top.bit。板载 100 MHz，经 MMCM 转为 CPU 25 MHz。CPU 连续执行，启动自测很快完成；按键、拨码稳定滤波约 10 ms。

程序构造真实整数 2026（年份）、7887（B 学号）、8704（A 学号），检查存取；对 2026、7887 加减、与或异或结果存储读回并校验，另验证 8704+2026=10730。包含条件分支两种结果、反向循环、无条件跳转。ROM 源码逐行附指令。

- K3/LED0：全部程序检查通过。
- H6/LED6：程序结果错误，LED1～5 显示失败编号的低到高五位。
- K1/LED7：CPU 故障。
- M1/LED1：学号轮播模式。
- S6/P15：低有效复位，按住立即复位，松开稳定约 10 ms 后重新执行。S5/PROG 不用作输入。

启动自测通过后进入内存操作模式：前四位显示槽位 0000～0255，后四位显示编辑值，初值 2026。按用户板上标号，SW0～7 全部作为槽位二进制选位，权重依次为 128、64、32、16、8、4、2、1，全部打开为 255。步骤为修改编辑值、按写入保存，切换槽位后按读取取回；切换拨码本身不自动读写内存。

| 按键 | 内存模式功能 |
|---|---|
| S0/R11 | 读取所选槽位到编辑值 |
| S1/R17 | 编辑值加 1，上限 9999 |
| S2/R15 | 编辑值减 1，下限 0 |
| S3/V1 | 编辑值写入所选槽位 |
| S4/U4 | 切换内存操作与学号轮播 |

学号模式前四位轮播 2026 → 7887 → 8704，每个约 2 秒，后四位关闭。切回后保留编辑值；轮播期间 S0～3 不操作内存。每次按键仅触发一次，长按不连发。同时按多个操作键时优先读取、加、减、写，建议一次只按一个。

演示槽位地址为 0x10000000 + 槽位×4，槽位 255 地址为 0x100003FC，覆盖全部 1 KB RAM。原自测完成后，256 个槽位由 CPU 程序逐一清零；复位会重新初始化，不保留演示数据。加减、地址计算、ld.w/st.w、模式和轮播选择均由 CPU 程序完成。sevenseg_display 只做十进制转换与扫描。当前综合日志识别 base/ram_reg 为 256×32，使用 32 个 RAM256X1S，即分布式 RAM，不是独立 Block RAM。

交互版已通过 tb_demo（全部 256 槽清零、0/128/255 独立存取、加减 1、上下限、两模式切换、复位）、tb_button_events（抖动、长按、松手后再按）、tb_display（十进制与扫描）、tb_cpu_twelve（原 12 条自测）、tb_ego1_demo（实际 MMCM 模型的整板输入输出仿真）。使用者已下载到实体板，确认内存读写与轮播显示正常。GUI 选择 tb_demo 顶层，Run All，预期 INTERACTIVE CPU TEST PASS。

MMIO 状态 0x1FFF0008：0 运行，1 通过，0x80000000|编号 失败。LED 数据 0x1FFF0000。数据 RAM 0x10000000～0x100003FF，先写后读。

新增应用外设（偏移基址 0x1FFF0000）：0x10 读八位槽位；0x18 读并清除五位按键事件，新事件优先于同时清除；0x1C 读两秒计时计数；0x20 读写后四位显示；0x28 读写模式指示。输入寄存器只读；0x14、0x24 保留，访问报错。前四位仍使用原 0x04 显示寄存器。scripts/generate_demo.cjs 可重建 ROM 中的交互程序，不需要用户手动运行。

包含 2026、7887、8704 的共同工程已通过功能仿真，使用者重新生成下载文件后确认实板只有 K3 亮。此前 2026、7887 版本的 25 MHz 实现时序 WNS=16.226 ns，并验证过复位重跑；该数值不作为新增数据后的时序记录。尚未实现流水线、乘除法。
